# MOSTO — Frontend (Vue 3 + Vite)

Proyecto base de frontend para la plataforma IoT de monitoreo y analítica predictiva de fermentación vitivinícola MOSTO.

## ⚡ Inicio Rápido

```bash
# 1. Entrar a la carpeta
cd frontend

# 2. Instalar dependencias (solo primera vez)
npm install

# 3. Iniciar el servidor local
npm run dev
```

Abre en tu navegador: **http://localhost:5173**
